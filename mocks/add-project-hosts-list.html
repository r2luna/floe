Add project — hosts listed in floe.toml

Hosts live in [projects] hosts in floe.toml. The modal lists them under MACHINE. Picking a row rewrites the host@ prefix in the head. Typing a new host@path still works, and a successful pair appends that host to the file. A listed host that is not paired yet pairs over ssh on its first add.

C1 · the config

Hand-edited or written by Floe. Tokens stay in the server plugin's config, not here.

[projects]
groups = ["Projects", "DevSquad"]
# Machines running Floe with serving on. Add project lists them;
# a new host@path that pairs is appended here.
hosts = ["gtt", "tahoe", "nas"]

M1 · local path, machines listed

M3 · a host not in the list

Typed by hand. It shows as a row marked new, and after pairing it is written to floe.toml, so it is listed next time.
