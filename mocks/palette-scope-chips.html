⌘P — sections in the list, filters top right

One shape in all four: chats above files under sticky headers, a scope filter in the top right that narrows to one kind, ⇥ to cycle it and ⌥1/⌥2/⌥3 to jump straight to one. What differs is only how the filter is drawn and where it sits — everything under the head is identical, so the choice is about the head alone.

V1 — Text chips with counts

The count on each chip is that scope under the current query, so the chips replace the head's single number: you see 34 files exist while reading the 4 chats. Active chip wears the accent outline (the app's only accent), never a fill.

V3 — One segmented control

Three chips welded into one box with hairlines between them, so the filter reads as a single control with a position rather than as three buttons you might have toggled independently. The active segment takes the neutral row wash — no accent, because the filter is a place you are, not a thing you did.
