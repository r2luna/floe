A — como está hoje

Cada chamada é uma linha de "ação", o comando inteiro, quebrando em 2–3 linhas.

* Bash ls /Users/r2luna; echo "---"; ls /Users/r2luna/.claude/projects/-Users-r2luna/memory/ 2>/dev/null; echo "---"; cat /Users/r2luna/CLAUDE.md 2>/dev/null | head -50
* Bash ls /Users/r2luna/code 2>/dev/null; echo "--- brain hits ---"; find /Users/r2luna/code /Users/r2luna/Obsidian -maxdepth 3 -iname "*brain*" 2>/dev/null | head -30
* Bash grep -ril "print" src tests docs 2>/dev/null | head -40; echo "=== src tree ==="; find src -maxdepth 2 -type d | head -40

B — uma linha por comando, truncada

O comando nunca quebra: cabe numa linha e o resto vira reticências. O primeiro token fica em negrito, porque é o que você lê para saber o que aconteceu.

$ ls /Users/r2luna; echo "---"; ls /Users/r2luna/.claude/projects/-Users-r2luna/memory/ 2>/dev/null; echo "---"; cat /Users/r2luna/CLAUDE.md 2>/dev/null | head -50
$ ls /Users/r2luna/code 2>/dev/null; echo "--- brain hits ---"; find /Users/r2luna/code /Users/r2luna/Obsidian -maxdepth 3 -iname "*brain*"
$ grep -ril "print" src tests docs 2>/dev/null | head -40; echo "=== src tree ==="; find src -maxdepth 2 -type d | head -40
$ wc -l src/Console/ShowBrainCommand.php src/Console/Printer.php

C — bloco de terminal

Comandos seguidos viram um bloco só, com a worktree no cabeçalho e a contagem à direita. Dentro, o mesmo truncamento de B.

bash brain 7 comandos · 14:26
$ ls /Users/r2luna; echo "---"; ls /Users/r2luna/.claude/projects/…
$ ls /Users/r2luna/code 2>/dev/null; echo "--- brain hits ---"; find …
$ grep -ril "print" src tests docs 2>/dev/null | head -40
$ wc -l src/Console/ShowBrainCommand.php src/Console/Printer.php

D — resumo semântico

A linha diz o que o comando fez, não como. O comando cru fica atrás do hover/expandir. Custa uma tabela de verbos (ls, grep, find, cat, sed, wc…) e cai para B no que não reconhecer.

$ listou ~/ +2 comandos
$ procurou *brain* em ~/code +1
$ buscou "print" em src tests docs
$ leu src/Console/Printer.php linhas 400–580

E — agrupado e colapsado

Uma linha para o bloco inteiro, com os alvos em vez dos comandos. Abre com Enter/clique e vira C. É o mais silencioso: sete chamadas ocupam o espaço de uma.

$ ls /Users/r2luna; echo "---"; ls /Users/r2luna/.claude/projects/…
$ grep -ril "print" src tests docs 2>/dev/null | head -40
