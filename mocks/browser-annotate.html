Browser annotate

Freeze the page, mark it from the keyboard or the mouse, then send the marked image and the elements under the marks to the composer. Enter from the browser panel with ⌘⇧N, or the palette command Annotate browser page.

S1. Annotating: press f, then a hint letter marks an element without the mouse

Hints come from a DOM map taken at capture time. Mark 1 is already placed. The yellow labels are the live hint layer.

S2. A second mark drawn by hand: every mark gets a one-line note

The note field takes focus as soon as a mark lands. Enter saves it and returns to the tool keys. Arrow and pen need a pointer, so element hints are their keyboard equivalent.

S3. Back in the composer: an ordinary image chip and editable text

The live page returns and focus lands at the end of the draft. Nothing is sent until you send it, and nothing is hidden: you can edit or delete any line. The chip and the "image 01" token are the existing attachment flow.

What each harness receives

Claude and Codex read both the image and the text. Opencode, Ollama and LM Studio are text-only in Floe today, so they still get the URL, selectors and notes. That is why the text is part of the feature and not a caption.
