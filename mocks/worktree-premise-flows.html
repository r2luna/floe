L6 — Draft, then confirm my pick

No interview by default. The model reads the branch name, the base diff, specs/<branch>/spec.md and the ticket key if the branch carries one, drafts the premise unattended and shows it for approval. Questions only when it cannot infer. Usually one keystroke. Silently wrong when the branch name lies — exactly when you needed it.
