Floe on Omarchy's app layout

Omarchy Quattro's application layout as Flea (thisisgm/flea) implements it, drawn with Floe's tokens, with Floe's content poured in. The rules copied: one mono face in three sizes (10 / 11 / 12), corner radius 0, two planes (chrome on surface, content on background), hairline separators, cursor row = accent bar on the left edge + accent text, section headings uppercase caption muted, glyph-only chrome controls, and a status bar that owns every count, transient line and key hint. Theme colours stay Floe's. Only the layout is Omarchy's.

F1 — main window, list mode chrome bar · tab strip · rail · pane · preview column · status bar

Flea's window, one to one: chrome bar with back/up and the crumb path on the left and glyph toggles on the right; the tab strip appears once a worktree has a second session; the rail lists what Floe's left column lists today, but as a flat rail with uppercase headings; the pane is the transcript; the preview column is Flea's media + facts table, here the session's facts and the file under review; the status bar carries the counts and the one transient sentence.

F3 — dialog, menu, settings DialogField · DialogButton · MenuRow with key column · SettingsRail · SettingsSegment

The small surfaces follow the same three rules: a field is background inside a hairline that turns accent on focus, a button is a hairline box with its key beside the label, a menu row keeps its chord in a right column so hints can be switched off without reflow. Settings is a rail + rows, each row a label with a caption sub-line and a segment or toggle on the right. No fills, no radius, no shadow.
