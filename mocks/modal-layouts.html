Modals — 6 layouts

Same content in all six: the Add project dialog (machine, group, path). Each is drawn over a miniature of the running app so the fit is judged against the surface it lands on. Reference at the top is what ships today.

Current — 620px box on a dark scrim

F1 it is the only surface in the app with its own head style (12/16px padding, no 34px head bar). F2 the scrim at 60% black hides the app you are adding to. F3 it ends in a Cancel/Add button pair, while every other flow ends in a key hint strip. F4 620px is wider than the sidebar it is about. F5 the scrim has no light-theme override, so on the white theme it lands as a grey slab.

O2 — Palette-shaped

Reuses the palette box exactly — same width, same top offset, same well, same footer of kbd actions. The fields are palette rows: ⏎ opens the row, ↑↓ moves. A dialog stops being a second kind of overlay and becomes the palette answering more than one question.
