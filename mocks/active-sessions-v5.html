RULES
  1. Favorites first. They stay in the order you starred them. A favorite leaves its project group, so it never shows twice, and carries its project as a tag.
  2. f toggles, the same key and bookmark mark as the skills panel. The mark shows only on starred rows. Unstarring puts the row back in its project group.
  3. Favorites never expire. They leave only when you unstar them, remove them, or close the chat.
  4. Everything else: projects A→Z. Inside a project, chats in creation order. Position never depends on time or status.
  5. Joins when you send a message or create the chat. Leaves when you close it, remove it (× / x), or after 24h idle. That cleanup runs only while the panel is off screen.
  6. A chat waiting on you shows even if it isn't in your list. It goes where its project group would put it.
  7. Numbers = position, for a jump key later.
