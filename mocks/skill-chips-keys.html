Floe — navigating the category chips from the keyboard

Three schemes for reaching the chips without leaving the composer. The constraint is that the textarea keeps focus the whole time — the menu never takes it, which is why every pick goes through onPointerDown with the default prevented.

What the menu already claims (Composer.tsx:619–649): ↑ ↓ move the row cursor · ⏎ and ⇥ both pick the row · Esc leaves the drill, then closes · → drills into a row only when that row has variants · ← leaves a drill only when you are in one · 1–9 answer a question when the box is empty.
So ⇥ is not available — it already picks. ← → are free in the skill menu, because a skill has no variants and no drill, and the code only ever claims them when there is somewhere to go.
